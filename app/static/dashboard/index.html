Evaluate forecast accuracy (backtest)

Hides the most recent days of real history, refits on everything before that, forecasts the hidden window, and compares the forecast against what actually happened — using the same dimension/filters and advanced settings selected above. A second model fit, so this is a separate check you run on demand, not part of every forecast.

A single held-out window is itself only a sample — on a thin or spiky corridor with little history, one backtest window can look better or worse than the model's true long-run accuracy. Treat this as a useful signal, not a guarantee.
